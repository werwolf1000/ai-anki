# `has_topic_picker_deck`

**Модуль:** [`app.live_coding`](../modules/app.live_coding.md)  
**Исходник:** `app/live_coding.py`

## Сигнатура

```python
def has_topic_picker_deck(deck: Deck) -> bool
```

## Описание

True, если в колоде **две или более** различных непустых темы на карточках. Desktop и web показывают диалог выбора темы перед стартом сессии.
