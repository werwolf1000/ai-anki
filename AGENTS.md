# Инструкции для агентов AI Anki

Перед работой прочитай проектный навык
[project-auto-commit](.agents/skills/project-auto-commit/SKILL.md) и применяй его
ко всем задачам, изменяющим этот репозиторий.

По постоянному указанию пользователя после каждой выполненной задачи создавай
локальный Git-коммит с проверенными изменениями задачи до финального ответа.
Дополнительное подтверждение не требуется. В ответе указывай хеш коммита.
Для задач без изменений не создавай пустые коммиты. Явное указание пользователя
не коммитить имеет приоритет. Push выполняй только по отдельной просьбе.
